ALL FOUR TOOLS MUST PREVIOUSLY BE INSTALLED, including Cppcheck, Flawfinder, gcc compiler, and Coverity

Guide to installing all tools:
1) Cppcheck
- Visit https://github.com/cppcheck-opensource/cppcheck/releases/download/2.20.0/cppcheck-2.20.0-x64-Setup.msi
- In your task bar search menu, search "environment variables" and click enter
- In the Advanced tab, click "Environment Variables"
- In System Variables, click "Path", then edit, then new
- Add the following to path: C:\ProgramFiles\Cppcheck\

2) Flawfinder
- Must have python installed
- Enter this command into a terminal: python -m pip install flawfinder
